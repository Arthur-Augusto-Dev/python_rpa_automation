Suite de Automação Python: RPA e Processamento de Dados

​Este repositório contém soluções práticas de automação desenvolvidas durante meus estudos, na minha graduação em Análise e Desenvolvimento de Sistemas (ADS). 
O projeto demonstra a transição de automações baseadas em interface (RPA) para pipelines de dados otimizados.

​Funcionalidades Principais

> ​Automação de Interface (automacao_interface.py): Utiliza PyAutoGUI para 
realizar o login e preenchimento de sistemas 
através de simulação de mouse e teclado.

> ​Pipeline de Dados (gerarador_planilha_dados.py): Script resiliente que processa 
arquivos CSV e gera relatórios profissionais em formato .xlsx (Excel/LibreOffice) 
utilizando a biblioteca Pandas.

> ​Tratamento de Erros: Sistema de verificação que garante que o arquivo final não saia vazio (0 KB), 
exibindo alertas visuais (✅/❌) no terminal.

​Tecnologias e Ferramentas
​> Linguagem: Python 3.14+
> ​Bibliotecas: Pandas, PyAutoGUI, Openpyxl
> ​Ambiente: VS Code integrado ao GitHub
> ​Compatibilidade: LibreOffice Calc e Microsoft Excel

​Aprendizado Extra
​O projeto foi adaptado para funcionar de forma offline e independente de servidores externos, demonstrando 
capacidade analítica para resolver imprevistos técnicos durante o desenvolvimento de software.
